# Blockout desde una cámara móvil

Proyecto de Visión por Computador (Ingeniería Electrónica, UTP, 2026‑II): visualización 3D interactiva
inspirada en *Blockout*, proyectada sobre una pantalla 2D mediante una matriz de cámara construida a mano.

Estado: en diseño. Ver [CONTRIBUTING.md](CONTRIBUTING.md) para el flujo de trabajo.
